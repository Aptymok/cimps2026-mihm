# 7. Difusión

**Entrada:** resultados derivados, configuración, provenance, hashes y límites de interpretación.

**Operaciones:** publicar notebook, Hub, evidencia derivada, fuentes LaTeX y comandos reproducibles sin redistribuir materiales cuya licencia lo impida.

**Salida:** paquete auditable accesible a un tercero.

**Regla:** la difusión separa datos fuente, datos derivados, interpretación y material editorial.
