# 3. Construcción

**Entrada:** especificación del instrumento y criterios de calidad.

**Operaciones:** implementar extractores por dominio, estados epistémicos, reglas de referencia/normalización, MTC, pruebas automatizadas, configuración versionada y contenedorización.

**Salida:** motor ejecutable cuya implementación puede contrastarse contra la especificación descrita en el manuscrito.

**Criterio de fallo:** una variable declarada sin extractor, fórmula o ruta reproducible permanece `UNRESOLVED`; no se emite un valor sustitutivo.
