# 8. Evaluación

**Entrada:** paquete auditable completo.

**Operaciones:** repetir ejecución, verificar hashes, contrastar resultados con ground truth/baselines, revisar missingness, identificar contradicciones y registrar hallazgos.

**Salida:** `PASS`, `FAIL`, `UNRESOLVED` o resultado negativo documentado por artefacto/hipótesis.

**Regla:** una reproducción que contradice el resultado original modifica el estado de evidencia; no se oculta ni se sustituye por una explicación narrativa.
