# 4. Recolección / ingesta

**Entrada:** activo local autorizado, URL pública/autorizada o dataset externo con condiciones de uso conocidas.

**Operaciones:** resolver la fuente, registrar URI/origen, metadatos, timestamp y SHA-256 de los bytes medidos. Los datasets que prohíben redistribución se descargan desde su fuente oficial durante la reproducción.

**Salida:** evidence record con provenance suficiente para identificar el objeto realmente observado.

**Regla:** nombre de archivo o etiqueta editorial no bastan para probar identidad entre modalidades.
