# 6. Análisis

**Entrada:** vector observado, referencia, perturbación/intervención, baseline y ground truth disponible.

**Operaciones:** calcular desplazamiento/estado, comparar con baselines, evaluar sensibilidad, incertidumbre, severidad y condiciones de fallo. Cuando existe una hipótesis preespecificada, el resultado negativo se conserva.

**Salida:** métricas, intervalos/pruebas cuando corresponda y conclusión acotada al instrumento.

**Regla:** un score no establece causalidad ni generalidad fuera del contrato que lo produjo.
