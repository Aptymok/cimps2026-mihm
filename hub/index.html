Contrato MIHM

Objeto → pregunta → evidencia → instrumento → vector → referencia → perturbación → contraste → estado → interpretación.

Regla multinodal

Los dominios no comparten features físicas por defecto. Su relación se declara mediante identidad, provenance, invariantes, alineación y pérdida explícita.

06

Política de datos

Reproducibilidad no equivale a redistribución.

CTC

Fluo-N2DL-HeLa se obtiene desde la fuente oficial. Dataset y annotations no se redistribuyen; el ground truth se mantiene separado de la construcción del instrumento.

KXTXR

Los medios pesados se resuelven desde activos autorizados o URLs públicas. Antes de medir se registra provenance, hash, timestamp y objeto declarado.
